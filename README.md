# Template LaTeX Tugas Akhir ITK

Repository template LaTeX untuk penulisan Tugas Akhir Institut Teknologi Kalimantan (ITK).

> **Status: sedang disiapkan.** Berkas utama LaTeX, gambar, dan PDF contoh belum seluruhnya tersedia di GitHub. Jangan menganggap repository ini sudah menjadi paket template siap pakai.

## Panduan untuk mahasiswa

Mulai dari [Panduan Pemula LaTeX](PANDUAN_PEMULA.md), termasuk langkah penggunaan Overleaf dan TeXstudio.

Setelah berkas template lengkap, pilih dokumen utama sesuai jenis Tugas Akhir:

| Jenis dokumen | Berkas utama |
| --- | --- |
| Skripsi | `main_skripsi.tex` |
| Proyek | `main_proyek.tex` |
| Prototipe | `main_prototipe.tex` |
| Artikel Ilmiah | `main_artikel_ilmiah.tex` |

File pendukung meliputi `itkta2025.cls`, `itkharvard.bst`, `referensi.bib`, dan folder `images/`.

## Catatan penggunaan

Template ini disusun sebagai alat bantu dengan mengacu pada panduan TA ITK 2025, bukan pernyataan pengesahan institusional. Ketentuan akademik mengikuti pedoman resmi ITK yang berlaku.

Jangan mengunggah naskah atau data sensitif mahasiswa ke repository publik.
